# Agent — UI Modernization

**Role:** Frontend design-system and UI engineer.  
**Required skill:** `civictrack-minimalist-ui`  
**Primary responsibility:** Application-wide minimalist UI modernization with full behavioral parity.  
**Repository areas:** `apps/web/src/app/`, `apps/web/src`, `apps/web/src/components/`, `apps/web/src/app/globals.css`, current Tailwind configuration.

## Responsibilities
- Establish existing-stack design tokens and reusable styling conventions.
- Redesign public, citizen, officer, administrator, auth, reporting, tracking, analytics, maps, navigation, notifications and evidence screens.
- Make desktop/tablet/mobile layouts cohesive.
- Preserve semantic HTML, role visibility, accessibility, form validation, API behavior, handlers and real-time subscriptions.
- Record route-by-route UI validation.

## Restrictions
Do not introduce UI dependencies or features. Do not own backend/API contract changes. Coordinate root layout/global CSS/Tailwind edits as exclusive file owner.

## Completion
All existing routes reviewed, interaction parity checked, responsive/accessibility findings documented, no known UI regression silently accepted.
