## 2. Test Suite Audit & Defects (`apps/server/tests/**` & `apps/web`)

2. **`tests/` Excluded from Server Typecheck**: `apps/server/tsconfig.json` compiles only `src/**/*`, hiding type mismatches inside test suites.

   - `tests/staff-auth.test.ts:229-234`: creates `TEST_DEPT` without `createdByAdminId`, causing live-DB invitation test (`L421`) to fail `403`, and leaves `TEST_DEPT` in DB.
   - `tests/socket-auth.test.ts:182-198`: creates `ComplaintModel` with 12-char `description` (`minlength: 20`), missing `address`, nested `location.address`, and unsupported `auditTrail` -> Mongoose `ValidationError` on live DB.
